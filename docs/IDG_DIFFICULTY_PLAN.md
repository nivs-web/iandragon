# 좀비와 드래곤 — 난이도 4단계 · 계정 레벨 999 · 명예의 전당 기획

> 2026-11-13 · 난이도 기획 담당. 숫자는 전부 계산기(`docs/sim` 의 전투 시뮬레이터 사본)로 직접 돌려 확인한 값이다.
> 이 문서는 **기획만** 한다 — 게임 코드 · `docs/sim` · 배포는 손대지 않았다. 맨 아래 «진행 기록»을 보면 어디까지 했는지 알 수 있다.

## 한눈에

1. 난이도는 **쉬움 · 보통 · 어려움 · 초고수** 4개. 쉬움 · 보통은 **그대로**(한 글자도 안 바꿈).
2. **어려움**은 «월드를 깨면»이 아니라 **보통 10-10 을 깨면** 열린다. 1-1 부터 차례로. 붉은 별.
3. **초고수**는 **어려움 10-10 을 깨면** 열린다. 1-1 부터 차례로. 보라 별. 보통 10-10 을 못 깬 사람에게는 **단추 자체가 없다**(존재를 모름). 어려움이 열린 사람에게만 자물쇠로 보인다.
4. 어려움 = «키우면 깬다»(권장 키우기 + 보통 솜씨로 70 ~ 85%). 초고수 = «**끝까지 키우고 그 판의 열쇠를 찾아야** 깬다»(끝까지 키우기 + 가장 좋은 수로 35 ~ 60%, **모든 판 25% 이상 = 못 깨는 판 없음**).
5. 숫자는 **판마다 따로** 맞췄다(100판 × 2 · 전투 계산 약 54만 판). 결과 : **어려움 99판 합격 · 1판(10-8) 실패 · 초고수 100판 전부 합격**(§B-7). 초고수에서는 밀치기로 좀비를 영영 묶어 두는 덱을 막으려고 **방패 역할 좀비 4종이 «굳센»(안 밀리는) 좀비로** 나온다.
6. 초고수에서는 부화 «+» · 편의품이 **통하지 않는다**. 현질 · 아이템빨이 아니라 덱 · 리더 · 화로 · 브레스 타이밍으로 이긴다.
7. **계정 레벨은 공식 그대로**(별 5개 = 1레벨). 어려움 · 초고수 별도 같은 값으로 더해 **99 뒤에도 100 · 101 … 로 이어진다**. 상한 999. 100 단위마다 배지 테두리 색만 한 단계 바뀐다.
8. **명예의 전당**은 한 화면에 **1 ~ 10위**가 다 보이게 줄을 촘촘히(줄 높이 65 → 52px). 내 순위 줄은 아래에 고정. **초고수 기록은 어디에도 올리지 않는다.**
9. 추천 순서 : **지금 있는 키우기로 먼저 낸다** → 드래곤캐슬 키우기가 들어오면 맞춤 프로그램을 다시 돌려 **숫자 파일만** 바꾼다.
10. 제작 예상 : 약 **13 ~ 15시간**(Opus 높음 지휘 + 보조 동시). 배포는 한 번에.

## A. 난이도 4단계 구조

### A-1. 이름 · 순서 · 열림

| 순서 | 이름 | 코드 id | 열리는 조건 | 별 | 판 순서 | 출전 드래곤 |
|---|---|---|---|---|---|---|
| 1 | 쉬움 | `easy` | 처음부터 | 노란 별(최대 2개) — 지금 그대로 | 보통과 같은 진행 | 그대로 |
| 2 | 보통 | `normal` | 처음부터 | 노란 별 3개 | 1-1 부터 | 그대로 |
| 3 | 어려움 | `hard` | **보통 10-10 승리** | **붉은 별** 3개 | **1-1 부터 차례로** | Lv21 바닥(낮으면 21 로 올려 줌) |
| 4 | 초고수 | `master` | **어려움 10-10 승리** | **보라 별** 3개 | **1-1 부터 차례로** | Lv21 바닥 · «+» · 편의품 무효 |

- **쉬움은 그대로 둔다.** 이유 : 어린 플레이어의 안전망이고, 보통을 «건드리지 않는다»는 원칙에 쉬움도 같이 묶는 것이 안전하다. 쉬움으로 깬 판도 지금처럼 보통 진행(`cleared`)에 센다.
- 쉬움 · 보통의 숫자, 별, 보상은 한 글자도 바꾸지 않는다.

### A-2. 단추가 보이는 방식 (스테이지 고르는 창)

| 플레이어 상태 | 쉬움 · 보통 | 어려움 | 초고수 |
|---|---|---|---|
| 보통 10-10 을 아직 못 깸 | 보임 | **자물쇠** + «보통 10-10 을 깨면 열려요» | **없음**(단추를 만들지 않는다 — 글자 · 빈 자리 · 그림자도 없음) |
| 보통 10-10 을 깸 | 보임 | 열림 | **자물쇠** + «어려움 10-10 을 깨면 열려요» |
| 어려움 10-10 을 깸 | 보임 | 열림 | 열림 |

- 초고수 단추는 `cleared >= 100` 일 때만 **만든다**(숨기는 것이 아니라 아예 그리지 않는다 → 화면 검사 · 접근성 글에도 안 나온다).
- 단추 3개일 때와 4개일 때 폭이 달라지지 않게, 4번째 자리는 3개일 때 **왼쪽 3개가 넓게** 차지한다(빈칸 금지).
- 열리는 연출(한 줄) :
  - 보통 10-10 승리 결과 창을 닫으면 → 날개 현판 «어려움이 열렸다! 붉은 별에 도전» + 초고수 자물쇠가 **쿵** 하고 내려앉는다(1회).
  - 어려움 10-10 승리 뒤 → 자물쇠가 **깨져 조각이 바닥에 남고**(투명하게 사라지지 않음) 현판 «초고수가 열렸다 — 이제 실력만 통한다».
- 판 순서 잠금 : 어려움 · 초고수 모두 `1-1` 만 열려 있고, 앞 판을 그 난이도로 깨야 다음 판이 열린다. 월드 건너뛰기 없음.

### A-3. 별 · 진행 저장

| 난이도 | 별 이름 · 색 | 저장 필드 | 진행 필드 | 별 기준 |
|---|---|---|---|---|
| 보통(쉬움 포함) | 별 · 노랑 | `stars[100]`(지금 그대로) | `cleared`(지금 그대로) | 지금 그대로 |
| 어려움 | 붉은 별 · 빨강 | `hardStars[100]`(지금 있음) | 계산 : 앞에서부터 이어진 `hardStars > 0` 개수 | 승리 1 · `star2` 초 안 2 · `star3` 초 안 3 |
| 초고수 | 보라 별 · 보라 | `masterStars[100]`(새로) | 계산 : 같은 방식 | 같은 방식 |

- 별 시간은 판마다 맞춤 프로그램이 낸다 : `star3 = 이기는 평균 시간 × 1.07`, `star2 = 이기는 평균 시간 × 1.27`(제한 시간 − 5초를 넘지 않게). 보통과 같은 비율.
- 별 그림 : 지금 붉은 별과 같은 도트 별에 색만 보라. 글씨 · 숫자는 1px 8방향 딱딱한 외곽선, 빛번짐 없음.

### A-4. 보상 (현질 없음 · 전부 플레이로)

| | 어려움 | 초고수 |
|---|---|---|
| 코인 | 보통의 1.5배(지금 값 그대로) | 보통의 2배 |
| 별 하나 처음 딸 때 | 젬 5 | 젬 10 |
| 중간 보스 판(x-5) 처음 깸 | 젬 40 | 젬 80 |
| 월드 보스 판(x-10) 처음 깸 | 젬 100 | 젬 200 + 그 월드 칭호 |
| 10-10 처음 깸 | 칭호 «붉은 별의 주인» + 붉은 테두리 | 칭호 «초고수» + 보라 불꽃 테두리 |
| 별 300개 전부 | 칭호 «완벽한 정복자» | 칭호 «전설의 드래곤 조련사» |

- 어려움 보상은 `IDG_DRAGON_CASTLE_PLAN.md` §8 의 값을 그대로 쓴다.
- 초고수 보상은 **꾸미기(칭호 · 테두리)가 중심**이다. 초고수는 이미 끝까지 키운 사람이 하므로 젬이 힘으로 바뀔 곳이 없다 → «돈으로 강해져서 깬다»가 생기지 않는다.
- 초고수 칭호 · 테두리는 **프로필과 명예의 전당 줄의 이름 옆에는 보인다**(자랑거리). 다만 초고수 «기록»(별 수 · 깬 판)은 전당에 올리지 않는다(§D-3).

### A-5. 지금 하고 있는 사람 (별을 뺏지 않는다)

| 상황 | 처리 |
|---|---|
| 이미 딴 붉은 별 | **전부 그대로.** 레벨 · 명예의 전당 «어려움» 순위에도 그대로 센다. 다시 계산하지 않는다. |
| 보통 10-10 을 깬 사람 | 어려움이 그대로 열려 있다. 붉은 별이 있는 판은 계속 다시 할 수 있고, 별이 없는 판은 «1-1 부터 차례로» 규칙을 따른다(앞 판에 붉은 별이 있으면 열림). |
| 보통 10-10 을 못 깼는데 붉은 별이 있는 사람 | 별은 유지, **어려움 입장은 잠김**(보통 10-10 을 깨면 다시 열림). 처음 한 번 안내 : «어려움이 더 강해져서 돌아왔어요. 모은 붉은 별은 그대로예요. 보통 10-10 을 깨면 다시 도전할 수 있어요.» |
| 저장된 난이도 선택이 `hard` 인데 잠긴 사람 | 조용히 `normal` 로 되돌린다(지금 `diffFor` 가 하는 일 그대로). |

계산기로 확인한 사실 :

- **수만 늘려서는 안 된다.** 월드 1 좀비를 7배로 늘리고 체력을 64배로 해도 Lv21 덱이 전부 이겼다(공격이 약해 방패가 안 죽음). 공격을 같이 올려야 진다 → «체력 배율 × 2 = 공격 배율»이라는 보통의 규칙을 그대로 따른다.
- **«한 방 금지»를 엄하게 걸면 오히려 스펀지가 된다.** 뚜껑을 «모든 좀비의 한 대 ≤ 돌등이 체력»으로 걸었더니 월드 1 은 체력 배율이 240 까지 올라가야 졌고, 자폭 좀비(공격 160)가 있는 월드 2 · 5 는 아예 맞출 수 없었다. 그래서 뚜껑은 **잡졸**에게만 건다.
- **초고수에는 그 뚜껑도 걸 수 없다.** 잡졸 뚜껑을 건 채 초고수를 맞췄더니 1-1 은 체력 배율 551(공격 배율은 217 에 묶임), 1-5 는 512, 2-1 은 범위 끝인 800 에서도 못 맞췄다 — 걷는 좀비 한 마리 체력이 5만인 «순수 스펀지»다. 그래서 초고수는 뚜껑 없이 체력 : 공격 = 보통과 같은 1 : 2 다. 어려움에서 뚜껑이 실제로 걸린 판은 2-1 · 6-1 · 6-5 처럼 몇 판뿐이고 조금만 걸린다(표에 «뚜껑» 표시).
- **월드 1 · 2 초고수는 배율로는 아예 맞출 수 없었다.** 뚜껑을 빼도 1-5 · 2-1 은 배율을 **5만 배**로 올려도 100% 이겼다(좀비가 한 대도 못 때림). 덱에서 하나씩 빼 보니 꼬물이 · 퉤퉤 · 얼음땡이 빠지면 0% — Lv30 퉤퉤(15% 밀치기) 여럿 + 얼음땡(100% 감속) + 꼬물이 물량으로 **좀비를 영영 묶어 두는 수**다. 월드 1 · 2 좀비에는 밀치기 면역 · 사거리 긴 좀비가 없어서 생긴다(월드 3 부터는 날개 · 얼리기 · 금속 · 골렘 때문에 안 된다). 성문 체력을 12배로 올려도 소용없었다. 방패 역할 좀비만 밀치기 면역으로 바꾸니 배율이 다시 들었다(1-5 : 배율 100 에서 50%, 300 에서 0%). → 처음에는 월드 1 · 2 에만 이 규칙을 넣었다(규칙 2).
- **그 «묶어 두기» 덱은 월드 3 · 5 · 6 · 8 에서도 통했다.** 100판을 맞춘 뒤 교차 검사(다른 판이 찾은 구성을 가져와 겨루기)를 해 보니 60판 중 42판에서 가져온 구성이 훨씬 잘했고, 그 구성으로 배율을 다시 맞추니 6-9 는 **401** · 6-4 는 270 · 8-1 은 248 · 5-4 는 233 · 5-2 는 180 까지 올라갔다 — 같은 판 어려움 배율의 5 ~ 8배. 공격은 한 대도 안 맞으니 의미가 없고 «제한 시간 안에 체력을 다 깎느냐»만 남는 **체력 스펀지**다. 방패 역할 좀비를 굳세게 하고 같은 덱을 돌리면 5-2 는 배율 45 에서도 0%, 8-1 은 120 에서 25%, 6-9 는 80 에서 2%, 3-9 는 99 에서 0% 가 된다(`probe19.js`). → **초고수에서는 모든 월드에서 방패 역할 좀비가 «굳센»(밀치기에 안 밀림) 좀비로 나온다(규칙 3).** 헬멧 좀비 · 용암 덩이 · 톱니 기사 · 독버섯 좀비 4종(모래 골렘은 원래 안 밀린다). 새 그림은 필요 없고(같은 그림), 데이터에 `shieldFirm` · `lavaFirm` · `gearFirm` · `shroomFirm` 네 줄이 는다. 어려움에는 넣지 않는다(어려움은 Lv21 ~ 24 라 묶어 두기가 안 된다 — 배율이 이미 정상).
- **승률은 배율에 아주 가파르다.** 10-10 어려움은 배율 9 에서 4판 전승, 13 에서 전패. 그래서 검증에서 띠를 벗어나면 «벗어난 만큼만»(최대 8%) 옮겨 다시 잰다.
- **한 방향으로만 변하지 않는 판이 있다.** 5-10(금속 대왕 로봇)은 낮은 배율에서 서로 못 뚫어 시간 초과가 난다 → 맞춤은 «위에서 아래로 훑어 처음 목표를 넘는 자리»를 찾는다(그냥 이분하면 엉뚱한 낮은 자리에 멈춘다).

### B-6. 사람 고수와 AI 의 차이 · 안전 여유

| | AI 가 나은 점 | 사람이 나은 점 |
|---|---|---|
| 손 | 5분 내내 0.5초(또는 0.2초) 반응, 실수 없음 | — |
| 머리 | 수백 번 해 보고 고른 덱 · 리더 | 브레스를 **몰린 곳에 겨냥**, 스킬을 **대왕이 나오는 순간**에, 지갑을 **고비 직전에 모아 둠**, 금속 · 비행 같은 상성 대응 |

- AI 의 최고 정책은 «규칙 몇 개를 고른 것»일 뿐 순간 판단은 못 한다 → 사람 고수의 천장은 AI 보다 높다. 반대로 보통 사람은 AI 보다 손이 느리다.
- 그래서 초고수의 목표를 **AI 최고 정책 48%**(쉬운 쪽)에 두고, **25% 바닥**을 «깰 수 있다는 증명»으로 삼는다 : AI 가 실제로 이긴 판의 덱 · 리더 · 씨앗이 결과 파일에 남아 있다.
- 다시 하기에 값이 들지 않으므로, 한 판 승률 35 ~ 60% 는 «서너 번 안에 깬다»는 뜻이다. 사람에게는 여기에 «열쇠를 찾는 시간»이 더해진다 — 그것이 초고수의 재미다.
- 마지막 확인은 손으로 : 대표님 · 겜부장이 초고수 1-1 · 5-5 · 10-10 을 다섯 판씩 해 보고, 느낌이 다르면 목표 승률(`TARGET.master`) 숫자 하나만 바꿔 다시 돌린다.

- 기존 플레이어의 레벨은 **내려가지 않는다**(별을 더하기만 한다). 이미 붉은 별이 있는 사람은 그만큼 레벨이 오른다(예 : 붉은 별 30개 → +6레벨).
- 경험치 막대(`xp = 별 % 5 ÷ 5`)도 같은 별 합계로 계산한다.

### C-3. 그래서 레벨이 어디까지 가나 (있는 그대로)

| 구간 | 필요한 별 | 어디서 나오나 | 걸리는 시간(어림) |
|---|---|---|---|
| Lv42 | 205 | 보통 | **약 2시간**(대표님 실제) |

### C-4. 181 뒤로도 올리고 싶으시면 (대표님이 고르실 것 — 기본은 «안 함»)

### F-3. 함수 · 데이터 형식 (제작자용)

  easy:   { name: '쉬움',   mag: 0.75, coin: 0.7, maxStar: 2 },          // 그대로
  normal: { name: '보통',   mag: 1,    coin: 1,   maxStar: 3 },          // 그대로

  master: { name: '초고수', coin: 2,   maxStar: 3, floorLv: 21, stages: 'master', star: 'masterStars', noPlus: true, noItems: true },
};
const run = (arr) => { let n = 0; while (n < 100 && arr?.[n] > 0) n++; return n; };      // 앞에서부터 이어 깬 판 수
export const diffUnlocked = (save, d) =>
  d === 'hard' ? (save?.cleared || 0) >= 100 : d === 'master' ? run(save?.hardStars) >= 100 : true;
export const diffVisible = (save, d) => d !== 'master' || (save?.cleared || 0) >= 100;   // 초고수 단추를 만들지 말지
export const diffOpen = (g, save, d) =>                                                  // 이 판에 들어갈 수 있나
  !DIFF[d].stages ? true : diffUnlocked(save, d) && (g === 1 || save[DIFF[d].star]?.[g - 2] > 0 || save[DIFF[d].star]?.[g - 1] > 0);
// iandragonGame.js
export const allStars = (g) => sum(g.stars) + sum(g.hardStars) + sum(g.masterStars);
export const levelOf = (g) => Math.min(999, 1 + Math.floor(allStars(g) / 5));
