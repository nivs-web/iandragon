# 좀비와 드래곤 — 로비 가로 · 세로 둘 다 기획

> 작성 : 겜팀장 · 2026-11-11 · 대표님 지시 «게임 가로 세로 둘 다 되는 거 좋은 것 같아. 로비도 가로 세로 둘 다 되게 하고 싶어 기획해 봐»
> 만드는 사람 : 화면 코드 = 겜부장 · 그림(가로용 배너 · 배경) = 겜부장 보조 · 소리 = 겜팀장(변경 없음)

## 0. 원칙

1. **어느 방향으로 들어도 막히지 않는다.** «돌려 주세요» 안내 · 경고 없음. 돌리는 순간 그 자리에서 배치만 바뀐다(다시 불러오기 없음, 듣던 음악 · 열린 창 그대로).
2. **같은 버튼, 같은 순서.** 가로든 세로든 버튼 이름 · 아이콘 · 순서는 같다. 손이 기억하는 위치만 바뀐다.
3. **어떤 비율에서도 버튼이 잘리지 않는다.** 아주 납작한 가로(21:9 폰 · 태블릿 가로)부터 길쭉한 세로(20:9)까지. 모자라면 배너가 먼저 줄어든다. 버튼은 끝까지 다 보인다.
4. **화면 아래 · 옆 안전 여백**을 지킨다(노치 · 홈 줄 · 브라우저 아래 줄). `env(safe-area-inset-*)` + 전체 화면 단추.

## 1. 세로 로비 (지금 모양을 다듬기)

```
┌──────────────┐
│  [배너 크게]   │  ← 화면 높이의 약 28%
│ 코인 · 젬 · ⚙ │
├──────────────┤
│ ▶ 모험 시작    │  ← 가장 크게
│ 용 둥지        │
│ 알 부화장      │
│ 친구와 하기    │
│ 주간 좀비 습격 │
├──────────────┤
│연구소 과제 시장 꾸미기 더보기│ ← 아래 작은 아이콘 한 줄
└──────────────┘
```

- 큰 버튼 5개는 세로로 쌓는다. 화면이 짧으면 «둥지 · 부화장», «친구 · 습격»을 2칸씩 나란히 놓아 4줄 → 3줄로 줄인다.
- 아래 아이콘 줄은 항상 화면 맨 아래에 붙인다(스크롤해도 따라옴).

## 2. 가로 로비 (새로)

```
┌───────────────────────────────────────┐
│ [배너 작게]          코인 · 젬 · ⚙ · ⛶  │ ← 위 띠: 배너는 화면 높이 약 22%, 왼쪽
├──────────────────┬────────────────────┤
│                  │ ▶ 모험 시작 (크게)   │
│  리더 드래곤      │ 용 둥지 │ 알 부화장  │
│  + 성 + 배경      │ 친구와  │ 주간 습격  │
│  (살아 움직임)    │                    │
├──────────────────┴────────────────────┤
│ 연구소 · 도전 과제 · 용 시장 · 꾸미기 · 더보기 │ ← 아래 띠
└───────────────────────────────────────┘
```

- **왼쪽 절반 = 볼거리** : 리더 드래곤이 성 위에서 숨쉬고, 재미 요소(부엉이 · 박쥐)가 지나가는 작은 무대. 누르면 리더가 이름 외침(name/<리더>) — 가로 화면이 심심하지 않게.
- **오른쪽 절반 = 버튼** : 맨 위 «모험 시작»을 가로로 길게, 그 아래 2×2 칸(둥지 · 부화장 · 친구와 · 습격).
- 배너는 가로에서 **작게**(대표님) : 위 띠 왼쪽에 로고만 크게 보이는 «짧은 배너»(가로 2.6 : 1 → 더 납작한 4 : 1 판)를 겜부장 보조가 따로 만든다. 없으면 지금 배너를 줄여 쓴다.
- 아주 납작한 화면(높이 360px 이하)에서는 왼쪽 무대를 접고 버튼만 3열로.

## 3. 창(상점 · 도감 · 둥지 · 음향 설정 · 더보기)

- 세로 : 지금처럼 화면 가운데 세로로 긴 창, 안에서 스크롤.
- 가로 : **좌우로 넓은 창**(화면 높이의 90% · 너비 80%). 목록은 2~3열 카드로 펴서 스크롤을 줄인다. 제목 띠는 창 위 가운데 고정(용 시장 제목 위로 붙는 버그 재발 금지).
- 창 안 스크롤은 손가락 끌기 · 휠 모두(모든 폰 · 브라우저). 닫기 버튼은 항상 보이는 자리(창 아래 또는 오른쪽 위).
- 창 그림(결과 창 일러스트 등)은 창 높이에 맞춰 줄어들고 절대 잘리지 않는다.

## 4. 전투로 넘어갈 때

- 전투는 지금 결정대로 가로 화면. 로비를 세로로 보다가 «모험 시작»을 누르면, 경고 없이 전투 화면이 가로로 그려진다(세로로 들고 있으면 화면이 옆으로 돈 채로 — 냥코처럼).
- 전투에서 나오면 기기 방향 그대로의 로비로 돌아온다.

## 5. 점검표 (배포 전 꼭)

| 화면 | 비율 |
|---|---|
| 폰 세로 | 20:9 · 19.5:9 · 16:9 |
| 폰 가로 | 20:9 · 16:9 |
| 태블릿 | 4:3 · 16:10 (가로 · 세로) |
| 브라우저 | 크롬 · 네이버 앱 · 웨일 · 삼성 인터넷 · 사파리 |

확인할 것 : 버튼 잘림 없음 · 배너가 버튼을 안 가림 · 창 스크롤 · 창 제목 가운데 · 돌릴 때 음악 끊김 없음 · 전체 화면 단추 동작.

## 6. 그림 부탁 (겜부장 보조)

- 가로용 짧은 배너(4 : 1 정도, 로고 위주)
- 가로 로비 왼쪽 무대 배경(성 + 달밤, 리더가 서는 자리)
- 가로에서 2×2 로 놓일 큰 버튼 판(지금 버튼과 같은 가족, 가로로 조금 긴 판)
