## 00_scene.jpg — 전체 장면 (달밤 초록 언덕)

**부장 생각 (고치면 좋을 곳)**
1. 멀리 있는 해골 성이 **떠 있는 판처럼** 보인다 → 언덕 위에 박혀 있게.
2. 달 빛무리가 **굵은 점무늬**라 거칠다 → 더 부드럽게 번지게.
3. 땅 근처에 **얇은 안개**가 깔리면 으스스함이 산다.
4. 캐릭터 · 소품에 **달빛 테두리**(위 · 왼쪽 가장자리가 연보라로 빛남)가 없어 배경과 따로 논다.
5. 가운데 묘지 줄이 너무 가지런하다 → 기울어진 묘비 · 비틀린 나무를 섞어 불규칙하게.

**수정용 프롬프트**
```
Edit this pixel art game screenshot. Keep the exact same layout, camera, ground line and pixel-art style.
Make the distant skull castle sit firmly on a rocky hill instead of floating, make the moon glow softer and smoother,
add thin low-lying mist along the ground, add pale purple moonlight rim light on the top-left edges of characters and props,
make the graveyard row irregular with tilted gravestones and twisted dead trees. Spooky-cute Halloween night mood.
```

## 01_castles.png — 양쪽 성 (체력 4단계)

**부장 생각**
1. 드래곤 성 돌이 **밤인데 너무 밝은 누런색** → 달빛 받은 푸른 회색 돌 + 횃불 쪽만 따뜻하게.
2. 횃불이 너무 작다 → **큰 화로(브레이저)** 로, 불빛이 벽에 번지게.
3. 드래곤 성에 **드래곤다운 장식**이 없다 → 지붕 끝 용머리 조각 · 성문 위 드래곤 문장 · 꼭대기 둥지를 더 크게.
4. 좀비 성은 해골 대문이 좋다. 탑 몸통이 밋밋하다 → 옆에 부서진 망루 · 가시 · 사슬 · 초록 연기를 더해 실루엣을 울퉁불퉁하게.
5. 체력 단계가 내려갈수록 **불 · 연기**가 보이면 더 극적이다.

**수정용 프롬프트**
```
Edit these two pixel art game bases, keep the same size, ground line, 4 damage stages and pixel-art style.
Dragon castle (top row): moonlit blue-grey stone instead of bright tan, large burning braziers with warm light spilling on the walls,
dragon head carvings on the tower top, a dragon crest above the gate, a bigger straw nest with eggs on the battlements.
Zombie fortress (bottom row): keep the skull gate, add a broken side watchtower, spikes, chains and green smoke to make the silhouette jagged.
In heavier damage stages add fire and smoke. Spooky-cute Halloween night mood.
```
