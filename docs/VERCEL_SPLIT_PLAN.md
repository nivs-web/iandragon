## 3. 무료로 오래 유지되나 — 한도 점검
| 서비스 | 무료 한도 | 오락실 예상 | 판단 |
|---|---|---|---|
| Vercel 배포 수 | 하루 100번 | main 에만 배포 → 하루 몇 번 | ✔ |
| Vercel 배포 저장 | 10 GB | 오래된 배포 자동 지우기 + 크기 줄이기 → 1~2 GB | ✔ (설정 필수) |
| Vercel 전송 | 월 100 GB · 요청 100만 | 지금 계정 전체가 3.3 GB · 38.7만. 좀비와 드래곤은 한 번 들어오면 수십 MB 받음 → 크기 줄이기로 대비 | ✔ (아이 수가 크게 늘면 다시 점검) |
| Vercel 용도 | «개인 · 비상업» | 오락실은 결제 · 광고 없음 | ✔ |
| Firebase 실시간 DB | **동시 접속 100** · 저장 1GB · 월 10GB | 멀티 한 판(2명) ≈ 시간당 약 11MB · 접속 표시 · 방 | ⚠ **동시 100명이 진짜 천장**(모든 오락실 게임 합계) |
| Firestore | 하루 읽기 5만 · 쓰기 2만 · 1GiB | 명예의 전당 열 때 50 읽기 → 하루 1,000번 열기 | ✔ |
| 구글 로그인 | 월 5만 명 | – | ✔ |
| GitHub | 공개 저장소 무료 | – | ✔ |
→ **결론 : 분리 뒤에도 무료로 유지 가능.** 단 ① 오래된 배포 자동 지우기 ② 배포 크기 줄이기 ③ main 에만 배포, 이 셋이 꼭 필요. 동시 접속 100명은 아이들이 크게 늘 때의 천장(그때 다시 판단).
