## 2. 만드는 방법 — 있는 길 그대로

참고 파일 (읽고 그대로 따라 한다) :

- `tools/build-jumprope-banner.mjs` — 3단계 전체 (192줄)
- `tools/_banner-art.mjs` — 도트 찍는 도구 모음 (제목 · 영어 글자 · 반짝이 · 빛살 …)
- `tools/build-jumppiano-banner.mjs` — 같은 방법으로 만든 두 번째 예

새 파일 :

- `tools/build-iandragon-banner.mjs` — 줄넘기 스크립트를 복사해 고친 것
- `tools/_banner-art-iandragon.mjs` — 이안 드래곤 전용 그림 (용 셋 · 좀비 셋 · 화로 · 불씨)

기존 파일에서 고치는 것은 **한 군데뿐** : `_banner-art.mjs` 의 영어 글자표 `FONT_B` 에 **D · G 두 글자 추가** (지금은 A C E H I J M N O P R U 와 빈칸만 있다). 기존 글자 · 함수는 건드리지 않는다 → 줄넘기 · 피아노 배너를 다시 구워도 결과가 그대로여야 한다.

### 1단계 — 바탕판 (줄넘기 스크립트와 똑같이)

1. `banner_catchball.webp` 를 바탕판으로 읽는다 (테두리 · 동전 더미 · 위 동전 · 은하 · 우주 배경을 **픽셀 그대로** 물려받는다).
2. 가운데 내용만 지운다. 지울 곳(원본 px) :
   `[212,50,588,232]` 제목 · `[288,204,512,288]` 공 · `[104,114,272,305]` 왼쪽 선수 · `[538,114,698,305]` 오른쪽 선수 · `[104,278,698,305]` 잔디 줄.
   동전 더미 가장자리(x < 186 또는 x > 640, y > 236)의 **금빛 칸은 남긴다** (`isGold` 그대로).
3. 지운 자리는 둘레 우주 배경의 색 흐름으로 채운다 (4px 칸 평균 → 확산 1,500번 → 3 × 3 덩어리로 칠함) + 도트 별 2.2%. 씨앗 · 별 색 그대로.
4. 캐릭터 발 사이로 동전 조각이 비쳐 보이면 그 자리를 통째로 지운다 (줄넘기 스크립트의 `KIDS` 줄과 같은 처리 — 용 · 좀비 자리에 맞게 다시 잡는다).

### 2단계 — 우리 그림 (투명 도트판 264 × 112)

- 판 크기 `W = 264, H = 112` (배너의 1/3). 외곽선 `#14082a`. 정수 칸 · 반투명 없음 · 그라디언트 없음.
- 그리는 순서 (뒤 → 앞) : 빛살 → 화로 → 불씨 → 용 셋 · 좀비 셋 → 제목 → 영어 → 반짝이.
- 자세한 자리 · 색은 3~5장.

### 3단계 — 합치기 · 저장

- 도트판을 **3배 nearest** 로 키워 바탕판 위에 올린다 → `webp({ lossless: true })`.
- 같이 만드는 것 :
  - `tools/_out/banner_iandragon_preview.png` (확인용)
  - `tools/_out/banner-compare-7.png` — 배너 7개를 한 장에 (2줄 × 4칸, 마지막이 이안 드래곤)
  - `public/assets/iandragon-logo.png` — 로비 · 타이틀 화면용 제목 로고 (투명, 도트 180칸 폭 × 3배 = 540px. 줄넘기 로고와 같은 방식)

## 3. 제목

| 항목 | 값 (줄넘기 배너와 같은 값) |
|---|---|
| 글자 | 「이안」 + 「드래곤」 — **한 줄**, 낱말 사이 7칸 |
| 글꼴 | 노토 산스 KR 800 (`C:/Windows/Fonts/NotoSansKR-VF.ttf`), 없으면 맑은 고딕 Bold (`malgunbd.ttf`, 700). **가면으로만** 쓴다 (문턱 128) — 글꼴의 부드러운 가장자리는 버린다 |
| 크기 | 36 → 16 으로 줄여 가며 **폭 196칸 · 높이 27칸 안에 들어가는 가장 큰 크기** (`fit(196, 27)`) |
| 자리 | 가로 가운데, 위에서 12칸 (`titleY = 12`) |
| 「이안」 색 띠 | `#fff8c8 #ffe85a #ffd21f #ffb21a #ff8a1a #ff5a1a` (노랑 → 주황), 입체 옆면 `#8a2a00` |
| 「드래곤」 색 띠 | `#f0fffa #a8fff0 #5ff0d0 #3fd890 #2fb8c8 #3a7dff` (하늘 → 초록 → 파랑), 입체 옆면 `#123a7a` |
| 입체 | 아래로 3칸 (`depth: 3`) |
| 테 | 진남색 `#0c0a26` 1칸 + 바깥 무지개 2칸 (`#ff3d6e #ff9a1a #ffe14d #4dd27a #3fc4ff #6a5cff #d24dff`, 제목 전체 폭에 걸쳐 왼 → 오) |
| 빛 번짐 | 없음 (`glow: null`) |

- 「이안 드래곤」은 5글자라 줄넘기(6글자)보다 **글자가 조금 더 크게** 잡힌다. 그대로 둔다 (높이 27칸 상한이 가족 느낌을 지킨다).
- 「래」 「곤」의 가로획이 뭉개져 보이면 굵기를 800 → 700 으로 내려 다시 본다. 그래도 안 되면 크기를 1 줄인다.

**영어** `IAN DRAGON`

- `B.pixelMask('IAN DRAGON', 1)` — 손으로 찍은 10줄짜리 굵은 도트 글자(`FONT_B`).
- **새 글자 D · G** 를 기존 글자와 같은 규칙으로 찍는다 : 높이 10줄 · 획 굵기 2칸 · 모서리 1칸 깎기. D 는 O 의 왼쪽을 곧게 세운 모양, G 는 C 에 가운데 가로획을 붙인 모양.
- 색 : 밝은 주황 `#ffa526` 단색 + 진남색 `#0c0a26` 테 1칸, 입체 없음 (`depth: 0, flat: true`).
- 자리 : 가로 가운데, 제목 아래 (`subY = titleY + 제목 높이 + 7`).

## 4. 인물 — 왼쪽 아기 용 셋, 오른쪽 좀비 셋

다른 배너는 양옆에 한 명씩이지만, 이 게임은 **"줄지어 나가 싸우는"** 게임이다. 그래서 양쪽에 **큰 것 하나 + 작은 것 둘**을 세워 "우리 편 줄 ↔ 좀비 줄"이 한눈에 보이게 한다. 큰 것 하나가 다른 배너의 인물 자리(같은 크기 · 같은 발 높이)를 그대로 차지하므로 가족 느낌은 유지된다.

| | 왼쪽 (오른쪽을 본다) | 오른쪽 (왼쪽을 본다) |
|---|---|---|
| 큰 것 (주인공) | **불똥이** — 볼이 빵빵한 주황 아기 용, 꼬리 끝 불씨. 입을 벌리고 신나게 뛰는 자세 | **어슬렁 좀비** — 두 팔을 앞으로 뻗고 어기적. 무섭지 않고 얼빠진 표정 |
| 작은 것 앞 | **꼬물이** — 통통한 연두 아기 용. 불똥이 앞(가운데 쪽)에서 폴짝 | **뼈다귀 멍멍이** — 좀비 앞(가운데 쪽)에서 뼈다귀를 물고 달려옴 |
| 작은 것 뒤 | **돌등이** — 돌 껍질 등, 졸린 눈. 불똥이 뒤에 반쯤 가려져 고개만 | **통통 좀비** — 어슬렁 좀비 뒤에 반쯤 가려진 둥근 덩치 |

자리 (도트판 264 × 112 기준)

- 큰 것의 머리 가운데 : 왼쪽 `x = 40`, 오른쪽 `x = 224` (줄넘기 배너 두 아이의 자리와 같다).
- **발 높이 `y = 101`** (줄넘기 배너의 아이 발 · 시상대 바닥과 같은 줄). 뛰는 자세면 2~4칸 뜬다.
- 큰 것 크기 : 약 **36 × 42칸** 안팎. 머리 꼭대기가 `y = 46` 위로 올라가지 않게 (제목 · 영어와 겹치지 않도록).
- 작은 것 앞 : 약 20 × 18칸. 왼쪽 `x = 66~90`, 오른쪽 `x = 174~198`.
- 작은 것 뒤 : 약 28 × 26칸. 바깥쪽으로 반쯤 가려지게. 테두리 줄(가장자리에서 10칸)과 닿지 않게.
- 가운데 화로 자리(`x = 100~164`)는 비워 둔다.

그리는 법

- 게임 안 스프라이트와 **같은 팔레트 · 같은 생김새**로, 칸 수만 늘려 배너용으로 다시 찍는다 (줄넘기 배너의 `bigKid` 가 게임 속 아이를 크게 다시 그린 것과 같은 방식). 게임 스프라이트를 정수 2배로 올려 보고 잘 어울리면 그것을 써도 된다.
- 외곽선 `#14082a` 1칸. 눈에 흰 반짝점 1칸. 색은 캐릭터당 6~8색.
- 아군은 맑고 따뜻한 색, 좀비는 칙칙한 초록 · 보라 살색 (기획서 12.6).
- **생김새는 전부 오리지널.** 다른 영화 · 게임의 캐릭터가 떠오르면 다시 그린다.

## 5. 가운데 — 화로와 불씨

이 게임의 상징은 **불씨**(전투 자원)와 **화로**(올릴까 말까의 딜레마)다.

- 빛살 : `B.rays(c, 132, 78, 22)` — 줄넘기 배너의 트로피 뒤 빛살과 같은 것.
- 화로 : 돌을 둥글게 쌓은 둥지 모양. 폭 약 44칸 · 높이 약 16칸, 바닥 `y = 102`, 가운데 `x = 132`. 회갈색 3색 + 외곽선.
- 불씨 : 화로 위에 큰 불꽃 하나. 폭 약 22칸 · 높이 약 28칸 (`y = 58~86`). 바깥 주황 `#ff8a1a` → 가운데 노랑 `#ffd21f` → 심지 연노랑 `#fff8c8` 의 3단 덩어리 (그라디언트가 아니라 색 띠). 동그란 눈 두 개와 웃는 입 — 작은 마스코트처럼.
- 불티 : 불꽃 둘레에 1~2칸짜리 불티 6~8개 (주황 · 노랑).
- 반짝이 : `B.sparkle` 4개 — `[86,66,큰 것] [180,64] [96,92] [170,92,큰 것]` (줄넘기 배너와 같은 자리에서 시작해 인물과 겹치면 옮긴다).

## 6. 오락실 카드에 붙이기

- `src/screens/Portal.js` 의 `CARDS` 에 한 줄 추가하고, 지금의 "7번째 게임 준비 중" 칸을 대신한다.

```js
{ id: 'iandragon', banner: 'banner_iandragon', title: '이안 드래곤', sub: (p) => …, screen: () => …, ready: false }
```

- `sub` 문구 예 : 깬 스테이지가 없으면 「아기 용을 모아 좀비를 막아라!」, 있으면 「3-4 · ★ 57」 (진행 스테이지 · 별 수). 문구는 `strings.ko.js` 에.
- **`ready` 는 대표님이 열라고 하실 때까지 `false`.**
- 카드에서 배너는 `.gc-art` (폭 100% · 비율 792/336 · 모서리 둥글게)로 보인다. 폰에서는 폭 약 400px 로 줄어든다 → **그 크기에서 제목이 읽히는지** 꼭 본다.

## 9. 문제 · 주의

| # | 내용 | 대응 |
|---|---|---|
| 1 | 앞의 4개 배너는 만든 기록이 없어 **완전히 같은 방법으로는 못 만든다** | 캐치볼 배너의 틀을 픽셀째 물려받는 줄넘기 방식이 지금 가장 비슷하게 나오는 길이다 |
| 2 | 영어 글자표에 **D · G 가 없다** | 2글자 추가 (3장) |
| 3 | 글꼴 파일이 PC 에 있어야 한다 (노토 산스 KR, 없으면 맑은 고딕) | 스크립트가 차례로 찾는다. 글꼴이 바뀌면 제목 모양이 조금 달라진다 → 줄넘기 배너를 만든 PC 에서 굽는 것이 가장 안전 |
| 4 | 양옆에 셋씩 세우면 다른 배너보다 **복잡해 보일 수 있다** | 비교 그림에서 튀면 「큰 것 하나 + 작은 것 하나」로 줄인다 (대표님이 고르시게 두 안을 같이 굽는다) |
| 5 | 배너는 게임 그림이 있어야 만들 수 있다 | 제작 9단계에 배치. 급하면 2단계(월드 1 그림) 직후에도 가능 |
| 6 | 오락실 저장소에 남의 작업 중 파일이 있다 (`src/data/font.generated.json` 수정됨, `tools/_out/*` 추적 안 됨) | 건드리지 않는다. 커밋할 때 내 파일만 골라 담는다 |
