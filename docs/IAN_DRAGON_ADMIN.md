# 좀비와 드래곤 — 운영자(관리자) 설정 · 난이도 연구 (겜부장 · 2026-11-11)

> 대표님 : «관리자 페이지에서 재미 요소 17종을 체크박스로 켜고 끄게 · 등장 빈도(몇 초에 한 번)를 설정 · 관리자가 난이도를 조절하면서 게임이 제공되게 — 연구하면서 진행»

## 1. 지금 만든 것 (작업 가지 · 8c925cb)
오락실 운영자 화면(통계 → 난이도 설정) 맨 아래에 «좀비와 드래곤» 칸 4묶음.

| 묶음 | 내용 | 기본 | 저장 자리 |
|---|---|---|---|
| 난이도 손잡이 4 | 좀비 체력 · 좀비 공격 · 불씨 벌이 · 내 성 체력 (1~99, **50 = 지금 그대로**, 1칸 ≈ 1.5%) | 50 | `config/tuning/zd` |
| 재미 요소 보이기 17 | 체크박스 · 전부 켜기/끄기 | **켬** | `config/switches/zdFun` |
| 재미 요소 소리 17 | 체크박스 · 전부 켜기/끄기 | **끔** | `config/switches/zdFunSound` |
| 등장 빈도 18 | «전체 간격»(다음 요소까지, 0.5~30초) + 요소마다 «다시 나오기까지»(3~300초) · 기본값으로 | 1.25초 · 요소별 지금 값 | `config/switches/zdFunEvery` |

- 쓰기는 **운영자만**(서버 규칙 `admins/{uid}`), 읽기는 앱에 들어올 때 한 번 → 기기에 저장 → 게임은 그 값을 바로 씀. 운영자 화면에는 즉시, 아이들은 **다음 접속부터** 바뀐다.
- ⚠ **서버 규칙 게시가 남았다** : `docs/FIREBASE_RULES.md` · `rtdb-rules.json` 은 고쳐 두었고 검사(`qa:rules`) 통과. 파이어베이스 콘솔에 게시해야 저장이 된다 — 바깥 서버를 바꾸는 일이라 **대표님 확인 후** 게시.
- 게임 쪽 : 전투 코어(계산)는 손대지 않는다. 판을 시작할 때 «스테이지 숫자»만 배율로 바꾼다 → 골든 300판 검사 · 50판 검사가 그대로 유효(50 이면 완전히 같다).

## 2. 재미 요소를 «방해 안 되게» 맞추는 법 (추천 사용 순서)
1. **먼저 전체 간격** : 기본 1.25초(1.0~1.5초). 정신없으면 **2.5~3초**로 — 화면에 동시에 떠 있는 요소가 절반 가까이로 준다.
2. **그다음 큰 볼거리만 드물게** : 자전거 · 번개 · 빗자루 둘의 «다시 나오기까지»를 40초 → 60~90초.
3. **그래도 거슬리는 것만 끄기** : 체크 해제. (앞쪽 흙에서 나오는 두더지 · 화면 위에서 내려오는 거미가 먼저 후보)
4. 소리는 전부 꺼 둔 채 시작 → 겜팀장 추천 7개(부엉이 · 까꿍 · 번개 · 박쥐 · 도깨비불 · 해골 딱딱 · 자전거)만 켜 보고 결정.
- 원래 규칙(동시 3개 · 큰 볼거리 하나씩 · 보스 때 3초 멈춤 · 배경 자리 규칙)은 운영자 값과 상관없이 늘 지킨다.

## 3. 난이도 — 어떻게 «관리자가 조절하면서» 제공할까 (연구)
### 3.1 원리
- 기본 난이도는 밸런스 계산기로 맞춘 값(보통 아이 기준 «되는 대로 눌러도 98% 깸, 별 3개는 어렵게»).
- 운영자 손잡이는 **전체 배율** — 모든 스테이지에 같이 곱한다. 스테이지 사이의 «점점 어려워지는 곡선»은 그대로 유지된다.

| 손잡이 | 무엇에 곱하나 | 50 → 60 이면 |
|---|---|---|
| 좀비 체력 | 스테이지 체력 배율(mag) | 좀비 맷집 +16% |
| 좀비 공격 | 스테이지 공격 배율(atkMag) | 좀비 공격 +16% |
| 불씨 벌이 | 불씨 생산 ÷ 배율 | 불씨 −14% (용을 덜 냄) |
| 내 성 체력 | 내 성 체력 ÷ 배율 | 내 성 −14% |

### 3.2 추천 운영 방법 (단계별)
1. **지금(1차)** : 손잡이 4개 · 전부 50 으로 시작 → 대표님 · 이안이 해 보고 «너무 쉽다/어렵다»면 한두 칸씩.
   - 너무 어렵다(막힌다) → **불씨 벌이 · 좀비 체력을 40~45** 로 (가장 티가 덜 나고 효과가 크다).
   - 너무 쉽다(별 3개가 쉽게 나온다) → 좀비 체력 55~60.
2. **다음(제안)** : «판 기록»을 모아 운영자 화면에 보여 주기 — 스테이지마다 **깬 비율 · 평균 시간 · 별 분포**. 오락실의 통계(`countPlay`)에 이 게임 값을 더하면 된다(서버 규칙 추가 = 대표님 승인). 그러면 «3-10 에서 아이들 40%가 진다» 같은 걸 보고 그 월드만 조절할 수 있다.
3. **그다음(제안)** : 손잡이를 **월드별**로 (예 : 월드 3 좀비 체력만 45). 지금 구조에 키만 더하면 된다.
4. **자동 도움(제안 · 아이용)** : 같은 판을 3번 지면 다음 판에 «용 응원(불씨 +20%)» 을 자동으로 — 운영자가 켜고 끄는 스위치로. 계산 코어는 그대로(시작 보너스만).

### 3.3 지켜야 할 것
- **멀티(3차)** 에서는 두 기기가 같은 숫자로 계산해야 한다 → 방장이 방을 만들 때 손잡이 값을 방 설정에 넣어 보내고, 둘 다 그 값으로 돈다(지금 캐시 값을 그대로 쓰면 어긋날 수 있음). 3차 때 같이 한다.
- 손잡이를 바꿔도 이미 딴 별 · 저장은 그대로. 바꾼 뒤 «별 기준 시간»은 그대로라 어렵게 하면 별이 더 어려워진다(의도).
