# 이안 드래곤 게임 — 캐릭터 움직임 규칙 · 그림 손질 기획 (v2)

> 작성 : 게임 부장 · 2026-11-10 · 대표님 지적 반영 : «대부분 발만 움직인다 · 눈을 안 깜빡인다 · 좀비 눈이 다 똑같다 · 팔을 대충 그렸다 · 성 위 드래곤이 드래곤 같지 않다 · 배경 · 성이 허술하다»
> 원칙 : **모든 캐릭터가 공통 규칙으로 조금씩이라도 움직인다** — 눈 · 입 · 팔(날개) · 몸통 · 머리 중 최소 3곳. 살아 있는 느낌이 곧 재미다.
> 담당 : 캐릭터 프레임 = 겜팀장 · 화면에서 섞어 쓰는 규칙(깜빡임 타이밍 · 엇박자 · 흔들림) = 겜부장 · **배경 · 양쪽 성 = 겜부장이 새로 그린다** (대표님 지시, 겜팀장이 소리 작업 중이라).

|---|---|---|

| 보스 (boss) | unit 11 + `roar0` `roar1` (등장 · 반피 때 포효) | 13 |

- 같은 캐릭터의 프레임끼리 **판 크기 · 기준점(발 가운데) 같게** (지금과 같음).
- `artManifest.js` 는 겜부장이 이 표대로 다시 만든다. 그 전 이름(walk0~1 · atk0~1)은 새 이름에 포함되므로 그대로 쓸 수 있다.

## 2. 모든 캐릭터 공통 — 이 다섯 곳이 움직인다

| 곳 | 쉬기(idle) | 걷기(walk 4장) | 공격(atk 3장) | 맞음(kb) |
|---|---|---|---|---|
| **몸통** | idle1 에서 1칸 위로 (숨쉬기) | walk1 · walk3 에서 1칸 위로 (통통 튐) | atk0 뒤로 2칸 젖힘 → atk1 앞으로 3칸 → atk2 제자리 | 뒤로 2칸 기울고 1칸 낮게 |
| **머리** | 몸통보다 반 박자 늦게 1칸 (idle0 아래 · idle1 위) | walk1 · walk3 에서 몸통보다 1칸 덜 움직임 (머리가 늦게 따라옴) | atk1 에서 앞으로 1칸 더 | 뒤로 젖힘 |
| **눈** | `blink0` = 눈 감은 쉬기 (화면이 2~5초마다 0.12초 섞는다) | 그대로 | atk0 가늘게(힘주기) → atk1 크게 | **X 눈 또는 질끈 감은 눈** |
| **입** | 닫음 | walk2 에서 살짝 벌림 (헥헥 · 좀비는 턱 덜렁) | atk1 에서 크게 벌림 | 벌림 |
| **팔 · 날개 · 꼬리** | 날개 · 꼬리 1칸 흔들 | **다리와 엇박자** — 왼다리 앞이면 오른팔 앞 (walk0 ↔ walk2 반대) · 날개는 walk1 위 / walk3 아래 · 꼬리는 반대쪽으로 1칸 | atk0 팔(앞발)을 뒤로 → atk1 휘두르기 (원거리는 입 · 손에서 발사 자세) | 팔을 들어 막는 자세 |

- **회전 금지** (도트가 깨진다) — 전부 부품을 1~3칸 옮기거나 다른 모양으로 바꿔 끼운다.
- 걷기 4장 = 접지 · 지나감 · 접지(반대발) · 지나감. 지금처럼 다리만 바뀌는 2장은 쓰지 않는다.

## 3. 좀비 전용 규칙 — 무섭고 웃기게

- **고개 까딱** : walk1 에서 고개가 앞으로 1칸 꺾이고 walk3 에서 옆으로 1칸 기운다 (불규칙해 보이게 두 방향을 섞는다).
- **팔** : 앞으로 뻗은 팔이 **위아래로 흔들린다** (walk 마다 1~2칸, 양팔 엇박자). 팔에 팔꿈치 · 손가락 끝을 그린다 (뭉툭한 막대 금지 — 손가락 2~3개, 찢어진 소매).
- **턱** : walk2 에서 턱이 1칸 덜렁 내려간다. atk1 에서 크게 벌려 이빨이 보인다.
- **걸음** : 질질 끄는 발 (한쪽 발이 walk1~2 동안 바닥에 끌림).

## 4. 용 전용 규칙 — 더 귀엽게

- **눈** : 큰 반짝 눈 유지 · `blink0` 는 웃는 반달 눈(감은 눈이 웃는 모양)이면 더 귀엽다.
- **날개** : 모든 용에 작은 날개가 있다면 walk 마다 퍼덕 (위 · 중간 · 아래 · 중간).
- **꼬리** : 끝이 1칸씩 좌우로 (몸통과 반대).
- **볼** : 공격 때 볼이 부풀었다가(atk0) 내뿜는다(atk1) — 불 · 침 · 물을 쏘는 용.

## 5. 리더 (성 위 드래곤) — 다시 그리기

대표님 : «드래곤이 아니다 · 더 디테일하게». 지금 노바트는 몸통 덩어리 + 작은 날개라 드래곤으로 안 읽힌다.

- 크기 **80 × 72칸** 안팎으로 키운다 (성 꼭대기에서 잘 보이게).
- 실루엣에 **드래곤 표시 5가지를 반드시** : ① 뿔 2개 ② 주둥이가 앞으로 나온 머리(콧구멍) ③ **펼친 박쥐 날개** (뼈대 + 막, 몸보다 크게) ④ 굵은 꼬리 + 끝 장식 ⑤ 발톱 있는 앞발 · 뒷발. 등에 가시 줄.
- 배는 비늘 줄무늬 (밝은 색 가로 띠).
- 자세 : 둥지 위에 앉아 고개를 들고 오른쪽(전장)을 본다.
- `idle0/1` 날개를 천천히 접었다 폈다 · `blink0` · `breath0` 고개를 뒤로 젖히고 볼 · 가슴이 빛남 → `breath1` 앞으로 내밀며 입을 크게.
- 다른 리더 9명도 같은 5가지 표시 + 리더마다 색 · 뿔 모양 · 날개 무늬로 구별.

## 6. 화면이 섞어 쓰는 규칙 (겜부장 코드 · 계산에 영향 없음)

| 규칙 | 값 |
|---|---|
| 쉬기 | idle0 ↔ idle1 0.5초마다 |
| 깜빡임 | 캐릭터마다 2~5초 무작위 간격으로 `blink0` 0.12초 (쉬는 중에만) |
| **엇박자** | 같은 용을 연달아 내보내도 걷기 · 쉬기 시작 프레임을 캐릭터마다 다르게 → 줄지어 걸어도 똑같이 안 움직인다 |
| 걷기 빠르기 | 이동 속도에 맞춰 초당 6~10장 (발이 미끄러지지 않게) |
| 공격 | 선딜(fore) 동안 atk0 → 타격 순간 atk1 0.1초 → 후딜(back) 동안 atk2 |
| 맞음 | 맞은 순간 1프레임 하얗게 번쩍 + 넉백 동안 kb0 |
| 좀비 신음 | 화면에 좀비가 새로 나올 때 가끔 고개 까딱 + 소리 `groan` |
| 보스 | 등장 · 반피에 roar0 → roar1 + 화면 흔들림 |

## 7. 배경 · 양쪽 성 (겜부장이 다시 그림)

- **하늘** : 색 띠 3~5개를 **Bayer 디더**로 부드럽게 잇는다 (줄무늬 · 엉성한 바둑판 금지). 위는 진하고 지평선 쪽은 밝게.
- **구름** : 원 여러 개를 겹친 뭉게구름 · 빛(왼쪽 위) 쪽 밝음 + 아래 그림자 3단 · 경계 디더 · 멀수록 작고 하늘색에 가깝게 (공기 원근).
- **먼 산 → 언덕 → 가까운 숲 → 땅** 4겹 : 멀수록 하늘색이 섞여 흐리고, 가까울수록 진하고 자세하게 (나무 · 덤불 · 꽃 · 바위 · 울타리). 512칸마다 이음매 없이 이어진다.
- **땅** : 풀 윗선에 풀잎이 늘어지고, 흙 층 · 작은 돌 · 뿌리.
- **월드마다 주제** : 1 초록 언덕 (맑은 낮) · 2 부글부글 화산 · 3 뭉게구름 하늘섬 · 4 꽁꽁 얼음골 · 5 덜컹덜컹 고철 광산.
- **내 성 (드래곤 둥지 탑)** : 둥근 돌탑 — 엇갈린 돌벽돌 + 줄눈 · 원통 명암 · 넓은 주춧돌 · 철 장식 나무문 · 불 켜진 아치 창 · 드래곤 깃발 · 성가퀴 위 **짚 둥지와 알** (리더가 여기 앉는다).
- **좀비 탑** : 기울어진 어두운 돌 + 판자 · 해골 장식(초록 눈빛) · 판자로 막은 창의 초록 빛 · 찢어진 보라 깃발 · 아래 뾰족 울타리 · 뼈 · 사슬. 월드마다 재질 (2 흑요석 + 용암 금 · 3 구름섬 나무 · 4 얼음 덮임 · 5 녹슨 철).
- **체력 단계 hp0~3** : 멀쩡 → 금 몇 개 → 벽돌 빠짐 · 성가퀴 부서짐 → 크게 무너짐 (연기는 화면 이펙트).
- 크기 : 성 **112 × 176칸** 안팎 (지금 96 × 160 → 조금 키움). 성은 겜부장 `art_env/` 폴더, 겜팀장 굽기 목록에 한 줄로 합친다.

## 8. 순서

1. 겜부장 : 월드 1 배경 + 양쪽 성 샘플 → **대표님 승인** → 월드 2~5.
2. 겜팀장 : 소리 작업이 끝나면 이 규칙으로 캐릭터 프레임 v2 (용 10 · 좀비 20 · 보스 5 · 리더 6). 노바트 · 어슬렁 좀비 · 꼬물이 3장을 먼저 → 대표님 승인 → 나머지.
3. 겜부장 : artManifest 를 1장 표대로 고치고, B2 화면에 6장 규칙을 넣는다.
