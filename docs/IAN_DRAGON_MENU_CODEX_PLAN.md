# 좀비와 드래곤 — 로비 메뉴 정리 · 도감 · 음향 설정 기획

> 작성 : 겜팀장 · 2026-11-11 · 대표님 지시(겜팀장 창에서 직접)
> 만드는 사람 : 화면 코드 = 겜부장 · 그림 = 겜부장 보조(제미나이) · 소리 · 음향 설정 기능 = 겜팀장

## 0. 대표님 말씀 (요지)

- 도감이 있으면 좋겠다. 좀비 도감 · 드래곤 도감 · 배경 구경하기. 에셋 갤러리처럼 잘 꾸며서 «볼맛 나고 눌러 보고 싶게».
- 로비 메뉴가 많으면 복잡하다. 메인 메뉴만 밖에 두고, 도감 · 하는 법 같은 보조 메뉴는 «더보기» 안으로.
- «설정»이라고 하면 무슨 설정인지 모른다. 실제로는 소리만 조절하니 **«음향 설정»** 으로 부른다.
- 용 카드를 눌러 내보낼 때 «탁» 누르는 그 순간 출격 소리가 나야 재밌다. 지금은 싸우는 중에 아무 때나 나는 것 같다.

## 1. 로비 메뉴 구성 (추천)

**큰 버튼 — 매일 하는 것만 밖에 (세로 화면, 위에서 아래로)**

| 순서 | 버튼 | 이유 |
|---|---|---|
| 1 | **모험 시작** (가장 크게, 이어 하기 겸용) | 게임의 중심 |
| 2 | **용 둥지** (레벨업 · 진화 · 출전 덱) | 판 사이에 가장 자주 감 |
| 3 | **알 부화장** | 보상을 쓰는 곳 · 기대감 |
| 4 | **친구와 하기** (같이 깨기 · 용 대결) | 3차 멀티 입구 하나로 묶음 |
| 5 | **주간 좀비 습격** (열렸을 때만 반짝) | 주마다 돌아오는 도전 |

**작은 아이콘 줄 — 화면 아래 한 줄**

- 연구소 · 도전 과제 · 꾸미기 · **더보기(⋯)**
- 연구소와 도전 과제는 «빨간 점»(받을 보상 · 올릴 수 있음)이 있을 때만 눈에 띄게 한다.

**«더보기» 창 (아래에서 올라오는 판, 큰 칸 2줄)**

| 칸 | 내용 |
|---|---|
| **도감** | 2장 |
| **게임하는 법** | 지금 «하는 법»을 그림 위주로 (불씨 · 화로 · 브레스 · 속성 상성 · 보스) |
| **음향 설정** | 3장 |
| **명예의 전당** | 습격 기록 · 친구 순위 |
| **음악 출처** | 지금 창 그대로 (CC BY 표기 의무) |
| (운영자만) 운영자 화면 | 운영자 계정일 때만 보임 |

→ 로비에서 보이는 버튼 수 : 지금보다 줄어 «큰 5 + 작은 4».

## 2. 도감 (볼맛 나게)

**들어가면 — 위쪽 탭 4개 + 모은 비율**

`드래곤 · 좀비 · 보스 · 배경`  ·  오른쪽 위에 «모은 수 37 / 64 · 58%» 막대.

**목록 (탭마다 공통)**

- 큰 카드 3칸 줄. 카드 = 그 캐릭터의 **실제 게임 그림**(ai/ 부품 조립본)이 숨쉬기 움직임으로 살아 있음.
- 아직 못 만난 것 : 까만 그림자 + «?» + «3-1 에서 만나요» 힌트 (스포일러는 그림자만).
- 카드 테두리 색 = 등급(스토리 · 희귀 · 영웅 · 전설) 또는 속성(빨강 · 날개 · 얼음 · 강철 · 유령 · 거대 · 그림자 · 수정).
- 처음 보는 카드에는 «NEW» 딱지 → 열어 보면 사라짐 (다시 보고 싶게).

**자세히 보기 (카드를 누르면 크게)**

- 왼쪽 큰 무대 : 그 캐릭터가 배경 위에서 **움직임을 차례로 보여 줌** — 쉬기 → 걷기 → 공격 → 맞음 (버튼으로 골라 보기도).
- **소리** : 열리는 순간
  - 드래곤 : 그 용 목소리로 이름 외침(name/<용>)
  - 좀비 : 좀비 소리(zombie_spawn)
  - 보스 : 등장 대사(boss/<id>)
  - 🔊 버튼으로 다시 듣기
- 모습 바꾸기 : 드래곤은 «1단 ↔ 진화» 탭, 좀비는 «기본 ↔ 맞았을 때», 보스는 «등장 ↔ 화남(반 피)».
- 정보 : 이름 · 속성 아이콘 · 등급 · 짧은 소개 한 줄(재미있게) · 능력 막대 4개(체력 · 공격 · 사거리 · 빠르기 — 숫자 대신 막대) · 잘 싸우는 상대 / 약한 상대 아이콘 · 처음 만나는 스테이지.
- 좌우로 넘기기(스와이프 · 화살표)로 다음 카드.

**배경 탭 — «구경하기»**

- 월드 1~10 배경을 큰 화면으로. 손가락으로 좌우 끌면 전장 전체를 훑어봄.
- 그 월드 배경음악이 같이 나옴(오케스트라 풍 / 오락실 풍 설정을 따름).
- 재미 요소(부엉이 · 박쥐 · 유령 고양이 …)가 실제처럼 나와서, 누르면 그 소리 + 작은 반응.
- 못 간 월드는 흐린 그림 + 자물쇠.

**모으는 재미**

- 탭마다 다 모으면 젬 보상(예: 드래곤 다 모음 30젬) · 도전 과제와 연결.
- 숫자 기록 : «이 좀비를 쓰러뜨린 수 1,284» — 좀비 카드에 나옴(싸운 만큼 쌓임).

**그림 (겜부장 보조 · 제미나이)** — 도감 틀(책 표지 느낌 프레임) · 탭 아이콘 4 · 카드 테두리 등급/속성별 · «NEW» 딱지 · 그림자 카드 · 자물쇠 · 더보기 아이콘 · 메뉴 칸 그림 6. 에셋 갤러리 화풍 그대로.

## 3. 음향 설정

| 항목 | 모양 | 기본 |
|---|---|---|
| 배경음악 크기 | 미끄럼 막대 0~100 | 80 |
| 효과음 크기 | 미끄럼 막대 | 80 |
| 목소리(대사) 크기 | 미끄럼 막대 | 90 |
| 좀비 소리 | 켜기/끄기 | 켜기 |
| 재미 요소 소리 | 켜기/끄기 | 운영자 기본값 따름 |
| 전체 소리 끄기 | 켜기/끄기 | 끄기 |

- 막대를 움직이면 **그 자리에서 바로 들리게** : 배경음악은 계속 나오고, 효과음 막대는 놓을 때 «띵», 목소리 막대는 놓을 때 짧은 대사 한 줄.
- 기기에 저장(다음에 켜도 그대로). 서버 저장은 필요 없음.
- 오케스트라 / 오락실 풍은 **운영자 화면에만** 둔다(대표님 결정 전까지 아이들 화면에는 안 보임).
- 소리 기능은 겜팀장이 `audio/index.js` 에 준비 : `setVolume('music' | 'sfx' | 'voice', 0~1)` · `getVolumes()` · `setZombieSound(on)` · 기기 저장 자동.

## 4. 출격 소리 — «탁» 누르는 그 순간

- 대표님 말씀 그대로 : «버튼을 누름과 동시에, 드래곤 생성 버튼 누르는 순간 리액션으로 나오는 소리. 눌렀을 때 이름을 여러 형태로 — 돌등이 준비완료! 돌등이 준비됐습니다! 등등».
- 용 카드를 누르는 **바로 그 프레임**에 : ① 버튼 «탁» 효과음 ② 그 용 이름 외침(name/<용>, **6줄** 무작위 — «돌등이!» · «돌등이 출격!» · «돌등이 출동한다!» · «돌등이 출발하겠습니다!» · «돌등이 준비 완료!» · «돌등이 준비됐습니다!») — 0.6초 간격 제한(이미 겜부장 연결). 용이 화면에 나타날 때가 아니라 **누르는 순간**.
- 전투 중 아무 때나 나오던 옛 출격 대사(deploy/<용>, 40% 확률)는 **끈다** — 이름 외침과 겹치고 «아무 때나 나는» 느낌의 원인. (대사 파일은 남겨 두고, 진화 · 크게 활약할 때 등 다른 자리에 나중에 쓸 수 있음.)
- 불씨가 모자라 못 내보낼 때는 이름 대신 «붑» (button_deny).

## 5. 순서 · 나누기

1. 겜팀장 : 음향 설정 기능(오늘) · 이름 외침 녹음 92줄(진행 중)
2. 겜부장 보조 : 도감 · 더보기 · 음향 설정 그림
3. 겜부장 : 로비 메뉴 정리 → 더보기 창 → 음향 설정 창 → 도감(목록 → 자세히 → 배경 탭) → 출격 소리 순간 확인
4. 정기 배포(한 시간에 한 번)에 맞춰 차례로 올림
