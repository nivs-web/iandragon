## 2. 만들 모양
```
게임(ianworld.vercel.app)  ──코드만(약 9 MB)──  Vercel
        │
        └─ 그림 · 소리 ──>  https://oraksil.onstori.com/idg/<판번호>/ai/…  ── R2 버킷 «oraksil-assets» (온스토리 버킷과 따로)
```
- **판 번호 폴더**(예 `idg/20261111a/`) : 그림을 고치면 새 판 번호로 올림 → 옛 캐시에 걸리지 않음 · 1년 캐시 가능 · 옛 판 3개만 남기고 지움
- 개발(이 컴퓨터 · 보조 · 겜팀장)은 **지금처럼** `public/assets/iandragon_game` 를 그대로 씀 → 세 세션 작업 방식 안 바뀜
- 운영 빌드만 경로를 R2 로 바꿔 끼움(빌드 때 글자 바꾸기 1곳) → 코드 25개 파일을 하나하나 고치지 않음(같은 값 두 곳 실수 방지)

## 5. 생길 수 있는 문제와 막는 법
| 위험 | 막는 법 |
|---|---|
| CORS 빠짐 → 그림 · 소리 안 나옴 | 4장 값 · r2:check 가 머리글 확인 · 배포 1차는 Vercel 파일도 남김 |
| 고친 그림이 옛 판으로 보임 | 판 번호 폴더 · 1년 캐시 |
| 보조 · 겜팀장이 새 그림을 넣었는데 R2 에 안 올라감 | 배포 전 `r2:idg` 가 달라진 것만 올림 · 배포 2차부터 빌드가 «빠진 파일» 있으면 실패(사이트가 깨진 채 올라가지 않음) |
| 한글 주소(오락실.onstori.com) | 브라우저 · 도구에서 «xn--…» 로 바뀌어 다루기 불편 → **영문 `oraksil.onstori.com` 추천** |
| 온스토리와 엉킴 | 버킷 따로 · 주소 따로 · 토큰은 이 버킷만 → 온스토리 사진에 손 못 댐 |
| 앱 저장(서비스 워커)이 R2 요청을 잘못 다룸 | sw.js 에서 다른 주소 요청은 그대로 통과 · 확인 |
| 비용 | 저장 10 GB · 읽기 월 1,000만 번 무료 · 나가는 전송 0원 → 지금 규모면 0원 |
| 비밀값 | 토큰은 대표님이 `.env.r2.local` 에(깃에 안 올라가게 막음) · 저는 값을 보거나 입력하지 않음 |
