# 좀비와 드래곤 — 모으기 · 꾸미기 진행 기획 (+ 속도 지키기)

> 대표님 핵심 임무(2026-11-13) : «드래곤과 드래곤캐슬이 다 들어가도 **게임 속도가 느려지면 절대 안 된다.** 드래곤 모으는 재미 · 드래곤 꾸미는 재미 · 드래곤캐슬 꾸미는 재미가 보통 · 어려움 · 초고수에서도 **끊기지 않게** 이어지게. 아이템 샵은 한 줄로 길게 말고 **위에 카테고리 → 하위 카테고리**(드래곤 → 모자 · 악세사리 …). 어려움 · 초고수도 해야 하니 **아이템 수를 많이**, 정말 구하기 힘든 **희귀 아이템까지** — 어려움을 끝까지 깨는 동안 하나하나 사고 꾸미는 재미.»
> 대표님 2차(같은 날) : «지금 구상하는 게 가장 싸다. 검토해서 잘 기획됐나 체크하고, **아이템 수 + 희귀 아이템 수를 더 늘린다.** 보통에서도 전설 드래곤을 거의 다 모았다(2마리 빼고). **«?» 물음표 드래곤**을 몇 마리 만들어 — 어려움 · 초고수에서만 나오는 드래곤, 아예 베일에 감춰 물음표로, **어려움에 들어가면 실루엣만** 보이게. 재미난 요소를 보통에서만이 아니라 어려움에 들어가서도 즐기게.»

## 1. 등급 6단계

| 등급 | 테 색(도트) | 얻는 곳 | 값(어림) |
|---|---|---|---|
| 보통 | 회색 | 샵 · 보통 월드에서 열림 | 코인 2,000 ~ 6,000 |
| 고급 | 초록 | 샵 · 보통 월드 | 코인 8,000 ~ 20,000 |
| 희귀 | 파랑 | 샵 · **어려움 월드**에서 열림 | 코인 25,000 ~ 60,000 + 젬 20 ~ 60 |
| 영웅 | 보라 | 샵 · **어려움 x-5 · x-10** 을 깨면 열림 | 코인 80,000 ~ 150,000 + 젬 80 ~ 200 |
| 전설 | 주황 | **판매 안 함** — 어려움 x-10 첫 클리어 확정 1개 · 어려움 보스 판 다시 깨기 2% | — |
| 신화 | 무지개 띠(3단 도트) | **판매 안 함** — 초고수 보스 첫 클리어 · 초고수 보스 판 다시 깨기 0.5% · 별 900개 | — |

- 젬으로만 사던 4개(왕관 · 해골 목걸이 · 황금 브레스 · 해골 깃발)는 **영웅**으로 옮긴다(값 그대로 · 이미 가진 사람 그대로).
- 레벨 선물(§C-5)의 «전설 2%»는 이 표의 **영웅**을 뜻하도록 맞춘다(판매 안 하는 전설 · 신화는 레벨 선물에서 안 나옴 → 희귀함 유지).
- 초고수 관련(신화 · 보라 모습)은 **보통 10-10 을 못 깬 계정에는 아예 안 보인다** — 목록 · 개수 · 모은 % 에서도 빠진다. 깬 계정에는 «???» 그림자 카드로 보이고, 조건 글은 «어려움 10-10 뒤의 도전에서 나와요».

## 3. 끊기지 않는 진행 — 언제 무엇이 열리나

### 3.1 월드 테마 묶음

월드마다 테마가 있다(언덕 · 화산 · 하늘 · 얼음 · 광산 · 묘지 · 사막 · 늪 · 수정 · 성). 꾸미기는 **테마 묶음**으로 나온다 — 같은 테마 물건을 다 모으면 «세트 완성» 칭호.

| 진행 | 열리는 것 (샵에 나옴) | 개수 |
|---|---|---|
| 처음 | 지금 있는 보통 · 고급 26개 중 보통 등급 | 약 12 |
| **보통 월드 n 깸** | 그 월드 테마 묶음 «기본» — 보통 2 · 고급 2 (예 : 화산 = 용암 고깔 · 숯불 목도리 · 화산 깃발 · 불씨 펫) + 드래곤 1마리 + 캐슬 단계 | 월드마다 4 → 40 |
| **어려움 월드 n 의 x-5 깸** | 그 월드 «붉은» 묶음 — 희귀 4 | 월드마다 4 → 40 |
| **어려움 x-5 깸(첫 클리어)** | 위 «붉은» 묶음 + **전설 1 확정 보상** | 전설 10 |
| **어려움 x-10 깸** | 영웅 2 샵에 열림 + **전설 1 확정 보상** + 대장 드래곤 «붉은 모습» 1 (+ 3-10 · 6-10 · 9-10 은 «?» 드래곤 §8) | 영웅 20 · 전설 10 · 붉은 모습 10 |
| **초고수 월드 n 의 x-10 깸** | **신화 1 확정 보상** + 대장 드래곤 «보라 모습» 1 (+ 4-10 · 7-10 · 10-10 은 «?» 드래곤 §8) | 신화 10 · 보라 모습 10 |
| 다시 깨기 | 어려움 보스 판(x-5 · x-10) 다시 깨면 «다시 깨기 전용 전설» 3% · 초고수 보스 판 «다시 깨기 전용 신화» 1% (가진 것은 안 나옴 · 판마다 1번까지) | 전설 10 · 신화 9 |
| 별 900개 | 신화 «별의 왕관»(모자) | 신화 1 |

- 그래서 **어려움 100판 내내 5판마다** 새 물건이 열린다(x-5 · x-10). 보통도 월드마다 열린다.
- 로비 왼쪽 위 레벨 배지 옆에 **«다음 목표» 한 줄** : 예 «어려움 3-5 → 붉은 묶음 4개» · «별 3개 더 → 레벨 선물». 누르면 그 판으로.
- **꾸미기 도감** : 꾸미기 창 위에 «모은 수 37 / 184». 25 · 50 · 75 · 100% 에 칭호 · 테두리. (초고수를 못 보는 계정은 분모에서 신화 · 보라 모습을 뺀다.)
- **오늘의 특가** : 열린 것 중 안 가진 것 3개를 30% 싸게(지금 그대로) — 매일 들어올 이유.

### 3.2 돈 맞춤 목표 (숫자는 핵심 보조가 계산기로 맞춘다)

| 목표 | 기준 |
|---|---|
| 보통 한 바퀴 | 업그레이드 권장치 + 보통 테마 묶음의 약 70% 를 살 수 있다 |
| 어려움 한 바퀴 | 어려움 권장치 + 붉은 묶음 · 영웅의 약 60% — **5판마다 1 ~ 2개를 살 수 있는 속도** |
| 끝까지 다 | 다시 깨기 · 초고수 코인 ×2 로 채운다 |

## 4. 아이템 샵 화면

```
┌──────────────────────────────────┐
│ ◀  아이템 샵            🪙 12,340 💎 85 │
│ [드래곤] [드래곤캐슬] [특가] [편의품]   │  ← 큰 메뉴 (4)
│ (모자)(목 장식)(브레스 색)(오라)(펫)    │  ← 하위 메뉴 (가로로 넘치면 좌우로만 밀림)
│ (드래곤)(강화)              12 / 20 │  ← 모은 수
│ ┌────┐┌────┐┌────┐                │
│ │ 🎩 ││ 🎩 ││ 🔒 │   ← 격자 3칸(세로) · 5칸(가로)
│ │보통 ││희귀 ││어려움│      카드 = 그림 · 이름 · 등급 테 · 효과 한 줄 · 값(아이콘 + 숫자)
│ └────┘└────┘└────┘                │
└──────────────────────────────────┘
```

| 큰 메뉴 | 하위 메뉴 |
|---|---|
| **드래곤** | 드래곤(구매 · 레벨업) · 강화(브레스 힘 · 사거리) · 모자 · 목 장식 · 브레스 색 · 오라 · 펫 |
| **드래곤캐슬** | 캐슬 단계 · 장비 · 깃발 · 지붕 · 성문 · 앞마당 |
| **특가** | 오늘의 특가 3개(지금 그대로) |
| **편의품** | 지금 그대로 3종 |

- 한 하위 메뉴는 많아야 20칸 → 세로 격자로 몇 줄만. **한 줄로 길게 가로 스크롤하지 않는다.**
- 카드 순서 : 살 수 있는 것 → 잠긴 것(열리는 조건 순서) → 가진 것. 위에 작은 거름 단추 «안 가진 것만».
- 잠긴 카드 : 자물쇠 + 조건 한 줄(«어려움 3-5 를 깨면 열려요»). 전설 · 신화는 «보스에게서 나와요»(신화는 초고수를 볼 수 있는 계정에만).
- 산 직후 «바로 입기». 샵은 사기만, 꾸미기 창은 입히기만(§3 그대로).
- 디자인은 지금 픽셀 UI 키트(결과 창 양식 · 날개 현판 · 탭 단추)를 그대로 쓴다. 새 모양을 만들지 않는다.
- 꾸미기 창도 같은 큰 칸 → 작은 칸 구조(드래곤 꾸미기 · 드래곤캐슬 꾸미기).

### 6.2 만드는 규칙

- **필요할 때만 불러오기** : 어려움 · 초고수 판 자료 · 아이템 샵 · 꾸미기 창 · 명예의 전당 · 꾸미기 시트는 처음 열 때 받는다(따로 묶음).
- **입은 것만** : 전투는 입은 꾸미기 그림만 받는다. 샵 · 도감 아이콘은 하위 메뉴마다 시트 1장(작은 webp).
- **판 시작 때 한 번 계산** : 꾸미기 효과 · 캐슬 단계 · 장비 · 드래곤 레벨은 판 시작 때 숫자로 굳힌다.
- **물체 재사용** : 수호 불꽃 · 포탄 · 터짐 · 조각은 미리 만든 것을 돌려 쓴다(풀). 한 번에 보이는 수 상한.
- **색 필터 없이** : 붉은 · 보라 모습은 미리 만든 파일. 전투 중 색 필터 · 흐림 필터 금지.
- 그림은 R2 에만, 1년 캐시. 새 그림은 새 이름.

### 6.3 재는 법

- `tools/idg-perf.mjs`(새로 · 머리 없는 크롬) : 로비 뜨는 시간 · 전투 시작 · 30초 평균 그림 수(CPU 4배 느리게) · 묶음 크기를 한 줄 표로.
- 합칠 때마다 겜부장이 돌리고, 진행 지도 «기록»에 숫자를 적는다. 배포 보고서에도 표로 넣는다.

## 8. «?» 비밀 드래곤 — 어려움 · 초고수에서만

| | 어려움 «?» 드래곤 | 초고수 «?» 드래곤 |
|---|---|---|
| 수 · 등급 | 3마리 · **전설** | 3마리 · **신화**(새 등급 · 무지개 테) |
| 얻는 곳 | 어려움 **3-10 · 6-10 · 9-10** 첫 클리어에 1마리씩 확정 | 초고수 **4-10 · 7-10 · 10-10** 첫 클리어에 1마리씩 확정 |
| 부화장 | 안 나옴(돈 · 젬으로 못 얻음 — 실력으로만) | 안 나옴 |
| 같은 드래곤 또 얻기(«+») | 어려움 · 초고수 보스 판 다시 깨기에서 «드래곤 조각» → 조각 10개 = «+1» (최대 «+10») | 같음 |

보이는 법 (드래곤 도감 · 파워업 카드 목록 · 부화장 목록)

| 플레이어 상태 | 어려움 «?» 드래곤 | 초고수 «?» 드래곤 |
|---|---|---|
| 보통 10-10 못 깸 | **«?» 카드**만 : 검은 카드에 커다란 물음표 · 이름 «???» · 한 줄 «아직 아무도 본 적 없는 드래곤». 몇 마리인지도 안 알려 준다(카드 3장만 맨 끝에) | **안 보임**(초고수 규칙) |
| 어려움에 들어감(보통 10-10 깸) | **실루엣**(검은 그림자 모양) + «어려움 3-10 에서 깨어나요» | **«?» 카드** + «어려움 10-10 뒤의 도전에서 깨어나요» |
| 초고수에 들어감(어려움 10-10 깸) | (얻었으면 정식 카드) | **실루엣** + «초고수 4-10 에서 깨어나요» |
| 얻음 | 깨어나는 연출(알이 아니라 **봉인된 돌**이 금 가고 → 조각이 바닥에 남고 → 드래곤 등장) · 이름 공개 · 도감 정식 카드 | 같음 + 무지개 테 |

- 실루엣은 정식 그림을 **검게 칠한 새 파일**로 미리 만든다(필터 X · 속도 영향 없음). «?» 카드는 그림 1장 공통.
- 세기 : 전설 · 신화라도 **지금 전설 3마리와 같은 힘의 띠**에 둔다(더 세지 않음 · 대신 특별한 재주 하나). 어려움 · 초고수 숫자 맞춤이 깨지지 않게. 재주 예(초안) : 쓰러진 아군 카드 한 장을 한 번 되살림 · 좀비 무리를 3초 뒤로 끌어당김 · 브레스 충전 +20% 오라 · 맞은 좀비가 다른 좀비에게 번지는 불 · 좀비 하나를 잠깐 아군으로 · 캐슬 앞에 3초 방패. 숫자는 핵심 보조가 계산기로 맞춘다.
- 이름 · 모습은 겜부장 디자인 지시서(②)에서 정한다. 어려움 3마리는 «붉은 별» 느낌, 초고수 3마리는 «보라 · 무지개 · 별자리» 느낌.
