## 3. 공통 규칙 (모든 직원)

- 같은 파일을 두 명이 고치지 않는다 — 자기 작업 폴더 · 자기 파일만. 합치기는 겜부장.
- push · 배포 금지(겜부장만). git stash 금지. 남의 파일 되돌리기 금지. 줄바꿈 유지.
- 그림 · 소리는 R2 에만. 기존 그림 파일 덮어쓰기 금지(새 이름).
- 픽셀 아트 · 글씨는 1px 8방향 딱딱한 외곽선 · 빛번짐 거의 없음 · 부서지면 조각이 남음 · 재화는 아이콘 + 숫자 · «비용» 대신 «불씨» · 이름은 «드래곤» · «드래곤캐슬».
- 시키지 않은 디자인 교체 금지 — 고치라는 것만, 원래 모양 위에서.
- 보통 10-10 을 못 깬 계정에는 «초고수» 글자가 어디에도 안 나온다.
- 미리보기 서버는 자기 포트만(5361 D · 5362 H · 5363 rigfix · 5364 겜보조 1 · 5365 겜보조 2), 끝나면 자기 PID 만 끈다.
- 구글 로그인 · Firebase · GCP 콘솔 페이지 열지 않는다.
- 제미나이 : 싼 모델(`gemini-3.1-flash-image`)만 · 장부 `iandragon/docs/style_refs/ledger.json` · 이번 묶음 $10.
