## 2. 결정 기록 (질문 → 추천안 → 이유 → 결과)

### D1 — 훈련소(레벨업)가 아직 없는데 용 레벨은?
- 질문 : 레벨업 화면(B4)이 생기기 전에 2-1 같은 뒤 스테이지를 하면 Lv1 용으로는 못 깬다. 어떻게 할까?
- 추천안 : **«저장된 레벨»과 «그 스테이지 권장 레벨(expLevel)» 중 큰 값으로 출전**. 훈련소가 생기면 그대로 저장 레벨이 올라가므로 코드 수정 없이 이어진다.
- 이유 : 대표님 목표가 «아침에 실제로 해 볼 수 있게» — 월드 1~5를 막힘 없이 끝까지 볼 수 있어야 한다. 밸런스 계산기도 권장 레벨 기준으로 맞춰져 있다(98% 깸).
- 결과 : 1-1 자동 플레이 38초 승리(★★). 덱 · 스킬 · 덱 칸은 스테이지 «unlocks» 글에서 자동으로 계산.

### D2 — 월드 2~5 배경을 어떻게 만들까?
- 질문 : 배경이 월드마다 다르면 재미 요소가 어색한 곳에 나온다(대표님 지적). 배경을 어떻게 주문할까?
- 추천안 : **모든 월드 배경에 같은 랜드마크 5개(왼쪽 마른 나무 · 달 · 오른쪽 먼 성 창문 · 울타리 · 묘비)를 고정 문구로 주문** + 배경마다 자리표를 재서 적고, 자리가 없으면 그 요소는 자동으로 끈다. 21:9 · 2K 한 장($0.10) = 540 높이에서 1273칸 → 전장 길이 그대로.
- 이유 : 배경을 여러 겹(먼 산 · 가까운 땅)으로 나누면 장수 · 돈 · 맞추는 시간이 4배. 한 장 + 같은 무대 배치가 가장 싸고 재미 요소와 잘 맞는다.
- 결과 : 월드 2 화산 배경 — 나무 가지 · 달 · 성 창문 · 쇠 울타리 · 흑요석 묘비가 다 나왔고 자리표 확인 그림(docs/review/spots_w02.png)에서 부엉이 · 고양이 자리가 정확.

### D3 — 연구소 · 보물 · 리더 고르기가 아직 없는데 뒤 월드가 안 깨진다
- 질문 : 처음 검사에서 월드 4~5 가 거의 다 졌다(24판 실패). 원인은 «덱을 아무렇게나 고름 · 리더가 늘 노바트 · 연구소/보물 보너스 0». 어떻게 할까?
- 추천안 : B4(연구소 · 보물 · 리더 고르기)가 생기기 전까지 **밸런스 계산기의 «기준 출전»을 그대로 쓴다** — 덱 = 꼬물이 · 돌등이 · 그 월드 필수 용 · 우선순위 순, 리더 = 월드마다 정해진 리더(월드 2 아쿠안티스 …), 보너스 = 연구소 (월드−1)레벨 + 지난 월드 보물.
- 이유 : 스테이지 숫자(적 체력 · 기지 체력)는 이 기준 출전으로 «98% 깬다»가 되도록 맞춰져 있다. 게임이 같은 조건이면 계산기 결과가 그대로 맞는다. 숫자를 따로 고치면 계산기와 게임이 어긋난다.
- 결과 : npm run qa:idg-play — 1-1~5-10 **50판 전부 깸** (보스 판 100~177초).

### D4 — 겜팀장 배너 v2 · 로비 배너를 대표님 확인 전에 연결할까?
- 질문 : 겜팀장이 «대표님 확인이 나면 로비 맨 위에 연결해 달라»고 했다. 대표님은 주무신다.
- 추천안 : **작업 가지(feat/iandragon-game)에만 연결**하고 main(오락실) 배포는 하지 않는다. 13시 보고에서 대표님이 보시고 «좋다/바꿔라»를 정하신다.
- 이유 : 대표님이 «로비 상단에도 이 배너를 쓴다»고 이미 말씀하셨다. 작업 가지는 아이들이 보는 오락실과 분리돼 있어 되돌리기 쉽다. 연결해 두어야 아침에 실제 화면으로 판단하실 수 있다.
- 결과 : 로비 맨 위 = banner_iandragon_lobby.webp. 재미 소리 17종은 «기본 꺼짐» 그대로(대표님이 고르실 일).

### D5 — 부화장에 어떤 용을 넣을까? (명령서 B6 «뽑기 용 5종» vs 데이터 11종)

- 이유 : 확률(희귀 70 · 슈퍼 25 · 전설 5)과 천장 50이 등급마다 용이 있어야 성립한다. 5종만 넣으면 등급 하나가 비거나 확률표를 바꿔야 한다. 돈 · 시간 부담이 작다.

### D6 — 뽑은 용을 어떻게 덱에 넣나?
- 질문 : 지금 덱은 계산기 기준 덱(결정 D3)이라 뽑은 용이 못 나간다.

- 이유 : 처음 하는 아이는 아무것도 안 골라도 잘 깨지는 기준 덱으로, 뽑기를 한 뒤에는 자기 용을 쓰는 재미가 생긴다.

- 추천안 : **항목마다 «기준»과 «내 연구소 + 보물» 중 큰 값**을 쓴다(레벨 D1 과 같은 방식).
- 이유 : 아침에 대표님 · 이안이 1~5월드를 막힘 없이 해 볼 수 있어야 한다. 그러면서도 연구소를 올리면 확실히 세지는 재미는 남는다. 기준을 넘는 투자만 효과가 보이는 점은 대표님께 여쭐 일(아래 «여쭐 것»)로 남김.
- 결과 : 연구소 · 보물 · 리더 화면. 50판 검사 그대로 전부 깸.

- 이유 : 처음 하는 아이는 추천대로 쉽게, 고르고 싶으면 고를 수 있게.
