# 좀비와 드래곤 — 창 패턴 규칙 (시작 · 결과 · 보상 · 확인 · 로비 창 · 알림)

> 대표님(11/13) : «시작할 때 창, 끝났을 때 결과 창 등등 디자인 패턴이 비슷한 것들은 **규칙을 만들어서 다 통일**되게 해라.» «게임하다 보면 예전 구식 스타일이 계속 나온다 — 전체적으로 점검해.» 단, «파워업 가로 모드 같은 건 전체 디자인과 달라도 됨».
> 바탕 규칙 = 코드 저장소 `docs/IDG_DESIGN_STYLESHEET.md`(색 · 글씨 5단계 · 창 구조 · 단추 색 뜻 · 재화 · 금지). 키트 = `src/styles/idg-kit.css` · `src/screens/idgKit.js`. 본보기 = 결과 창(`render/hud.js` `resultCard`).
> 이 문서는 그 위에 **«창 종류마다 무엇을 어떤 차례로 놓는지»**를 정한다. 새 창을 만들거나 고칠 때는 아래 6가지 중 하나에 맞춘다. 맞는 것이 없으면 겜부장에게 먼저.

## 0. 공통 (모든 창)

| 항목 | 규칙 |
|---|---|
| 창 테 | 호박 창 테 `dialog9` (`.idg-k-win`) — 다른 테 금지 |
| 제목 | 빨간 날개 현판(`.idg-k-title`) — 창마다 하나 |
| 글씨 | Pretendard 굵게 + 1px(작은 글씨) · 2px(큰 글씨 · 단추) 8방향 딱딱한 외곽선 · 크기 5단계만(t1 ~ t5) |
| 단추 뜻 | **빨강 = 앞으로 가는 주 행동 하나**(시작 · 다음 판 · 다시하기) · **초록 = 좋은 일**(받기 · 사기 · 파워업 · 명예의 전당) · **보라 = 보조**(나가기 · 닫기 · 뒤로) · 살 때는 가격 단추 |
| 재화 · 기록 | 아이콘 + 숫자만(«코인 · 금화 · 젬 · 비용» 글자 금지 · «비용» 대신 «불씨») |
| 덮개 | 창이 뜨면 뒤 화면 **전체**(아래 출전 슬롯 숫자 · 필살기 글씨 포함)가 같이 어두워진다 |
| 움직임 | 나타날 때 «쿵 · 통통» 짧게 · 사라질 때 «싹» — **투명하게 서서히 사라지기 금지** · 흐린 빛번짐 금지 |
| 방향 | 전투 쪽 창(시작 · 결과 · 일시정지)은 **가로 기준**, 로비 쪽 창은 **세로 기준** |
| 낱말 | «드래곤» · «드래곤캐슬»(«용 · 성» 금지) · 아이들이 아는 쉬운 말(«2026-W46» 같은 기호 금지 → «이번 주») |

## 1. 시작 창 (판 시작 카드 · 주간 습격 소개 · 드래곤 대결 · 같이 깨기 시작)

```
[현판 : 판 이름 또는 모드 이름]
[그림 띠 : 포스터 · 장면 그림 — 또는 «나오는 좀비» 얼굴 칸 줄]
[큰 한 줄 목표 (t1) : «10-2 를 깨라!» · «최대한 오래 버텨라!» · «상대 드래곤캐슬을 먼저 부숴라!»]
[정보 3줄까지 : 아이콘 + 짧은 글 (t3) — 규칙 · 특별한 점 · 난이도 문구]
[별 기준 줄 (있으면) : 별 아이콘 + 시간 · 별 아이콘 + 시간]
[단추 줄 : 빨강 «시작하기» · 보라 «나가기»]
```

- 창이 떠 있는 동안 전투는 **멈춰 있다**. «시작하기»를 눌러야 시작한다.
- 모드마다 목표 한 줄이 반드시 있다 → «이게 뭐 하는 게임이지?»가 생기지 않게.
- 같은 판을 다시 시작할 때는 작게(그림 띠 없이) 1초 뒤 자동으로 넘어가도 된다.

## 2. 결과 창 (모든 모드의 승리 · 패배 · 시간 초과 · 기록 · 대결 이김/짐/비김)

```
[장면 그림 : 승리 · 패배 · 습격 · 대결 그림 — 위에 날개 현판 «승리» · «패배» · «웨이브 17!» · «이겼다» · «졌다» · «비김»]
[가운데 : 별 3개 (판) — 별이 없는 모드는 큰 숫자 (웨이브 수 · 점수)]
[보상 알약 줄 : 시계 + 시간 | 코인 아이콘 + 숫자 | 젬 아이콘 + 숫자 | (그 밖 아이콘 + 숫자)]
[한 줄 (종이 띠 · 있으면) : 새 기록 · 도움말 · 새로 열림]
[단추 줄 : 빨강 주 행동(다음 판 · 다시하기) · 초록 좋은 일(파워업 · 명예의 전당) — 아래 보라 «나가기»]
```

- 싱글(쉬움 · 보통 · 어려움 · 초고수) · 같이 깨기 · 드래곤 대결 · 주간 습격 · 그 밖 모드 **전부 이 한 모양**. 모드마다 다른 것은 그림 · 현판 글자 · 가운데(별/숫자) · 단추 이름뿐.
- 결과 창 뒤 HUD 전체가 어두워진다(공통 «덮개»).

## 3. 보상 · 선물 창 (레벨 선물 · 첫 클리어 보상 · 칭호 · 테두리 · «?» 드래곤 깨어남)

```
[현판 : «선물 상자 4개» · «새 칭호!» · «드래곤이 깨어났다!»]
[큰 그림 (상자 · 봉인된 돌 · 드래곤) — 연출 뒤 조각이 바닥에 남음]
[카드 격자 : 그림 + 이름 + 등급 색 테 + 도트 별 (★1 ~ ★6)]
[합계 알약 : 젬 아이콘 + 숫자]
[작은 꼬리 글 (t5 · 있으면) : 확률]
[단추 줄 : 초록 «입어 보기» · «받기» · 보라 «닫기»]
```

## 4. 확인 창 (나가기 · 사기 · 지우기 · 초기화)

```
[현판 : 짧은 질문 제목]
[종이 판 한 줄 : «정말 나갈까요? 이번 판 기록은 남지 않아요.»]
[단추 줄 : 빨강 또는 초록 «예» · 보라 «아니요»]
```

- 작은 창(세로 너비의 80% · 가로 너비의 50%).

## 5. 로비 창 (샵 · 꾸미기 · 명예의 전당 · 스테이지 · 부화장 · 도감 · 설정 · 프로필 · 파워업 세로)

```
[현판 + 오른쪽 위 X 하나 (아래 «닫기» 단추 없음)]
[지갑 판 (사고파는 창만) : 코인 아이콘 + 숫자 | 젬 아이콘 + 숫자 — 숫자가 커져도 옆 칸을 가리지 않게]
[큰 탭 → 작은 단추 줄 (넘치면 좌우로만 밀림)]
[본문 : 격자(세로 3칸) 또는 목록 줄 — 본문만 스크롤]
[아래 설명 줄 (카드를 누르면) : 효과 · 조건 · 단추]
```

- 닫는 방법은 X 하나(스타일 시트 §4 «하나만» 그대로).
- 세로 390×844 · 360×640 둘 다에서 잘림 · 겹침 없음.

## 6. 알림 현판 (어려움 열림 · 새 기록 · 레벨 100 · 세트 완성)

- 날개 현판 한 줄(t1~t2) · 화면 가운데 위 · 약 1.5초 · 나타날 때 «쿵» · 사라질 때 «싹».
- 덮개 없음 · 게임을 막지 않는다.

## 7. 예외

- **파워업 가로(전투 중)** — 대표님 허락으로 전체 디자인과 달라도 된다(시안 B 그대로).
- 필살기 제목 띠(브레스 · 으르렁 등) — `IDG_DRAGON_CASTLE_PLAN.md` §13.3 따로.

## 8. 점검 (배포 전 · 겜부장)

- 모든 모드 결과 창 · 시작 창을 한 장 모음으로 찍어 위 1 · 2 와 칸 차례가 같은지 본다.
- 옛 모양(테 없는 창 · 글자만 있는 단추 · «코인» 글자 · 흐린 그림자 글씨 · 아래 «닫기» + X 둘 다)이 하나라도 남아 있으면 배포하지 않는다.
